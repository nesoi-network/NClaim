NClaim is a free land claim plugin for **Paper and Folia 1.21.4+** (including 26.x).
Players claim chunks to protect their builds and manage everything from in-game menus: no commands to memorise.

## Features

- **GUI-first chunk claims:** claim, expand, rename, sell or delete from a menu, also remotely.
- **Co-op with 53 permissions** in 9 categories, set per player.
- **Claim market:** list claims for sale and browse them in game.
- **Claim value and leaderboards:** valuable blocks raise a claim's value; works with ajLeaderboards.
- **Borders and holograms built in:** coloured border walls and text-display holograms, no extra plugin.
- **Per-claim protection settings:** PvP, explosions, mob spawning, mob griefing, fire spread, crop trampling and more.
- **Expiration:** claims expire after a configurable time unless extended.
- **Folia ready**, YAML / SQLite / MySQL storage, safe config updates.

**Works with:** Vault, PlaceholderAPI, WorldGuard, PvPManager, Farmer, AxSellwands, SkinsRestorer, ItemsAdder, Nexo, Oraxen.

## Quick start

1. Download from [Modrinth](https://modrinth.com/plugin/nclaim) or [GitHub Releases](https://github.com/nesoi-network/NClaim/releases).
2. Put the jar in `plugins/` and restart (Java 21+).
3. Type `/nclaim` in game.

Commands, permissions, placeholders, configuration and upgrading from 3.x: **[NClaim Wiki](https://github.com/nesoi-network/NClaim/wiki)**.

## Building

```bash
./gradlew build          # -> build/libs/NClaim-<version>.jar
./gradlew runServer      # Paper test server
./gradlew runFolia       # Folia test server
```
